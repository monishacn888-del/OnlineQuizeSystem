# Online Quiz System 📝

## 📌 Project Description

The Online Quiz System is a simple web-based application designed to conduct multiple-choice quizzes in an easy and interactive way. Students can enter their name, answer quiz questions, and receive their score automatically after completing the quiz.

## 🚀 Features

- Student name input
- Multiple-choice questions
- Interactive quiz interface
- Automatic answer checking
- Automatic score calculation
- Final result display
- Try Again option

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
